# Arthas MCP Server

# 概览

Arthas MCP Server 是 Arthas 的实验性模块，实现了基于 MCP（Model Context Protocol）在新窗口打开 协议的服务端。该模块通过 HTTP/Netty 提供统一的 JSON-RPC 2.0 接口，使 AI 助手能够通过工具调用的方式执行 Arthas 诊断命令。

MCP（Model Context Protocol）是由 Anthropic 提出的一种标准化协议，用于连接 AI 助手与各种工具和数据源。通过 Arthas MCP Server，AI 助手可以自然地执行 Java 应用诊断任务，大幅提升开发和运维效率。

# 主要特性

  • AI 原生集成：支持主流 AI 客户端（Claude Desktop、Cherry Studio、Cline 等）
  • 标准化协议：完整实现 MCP 协议规范（版本 2025-06-18），支持 Streamable Http 传输
  • 29 个诊断工具：涵盖 JVM 监控、类加载、方法追踪等核心功能
  • 安全认证：支持 Bearer Token 认证机制

# 支持的诊断工具

Arthas MCP Server 集成了 29 个诊断工具，按功能分类如下：

# 快速开始

# 1. 配置 MCP 服务

在 arthas.properties 配置文件中启用 MCP 服务：

# MCP (Model Context Protocol) configuration
arthas.mcpEndpoint=/mcp

# 2. 启动应用

正常启动 Arthas 或带有 Arthas 的 Java 应用。默认情况下，MCP 服务会在 HTTP 端口 8563 上暴露。

验证 MCP 服务是否启动：

curl http://localhost:8563/mcp

如果返回 MCP 协议信息，说明服务已成功启动。

# 3. 配置 AI 客户端

以下是几种主流 AI 客户端的配置方式：

# Cherry Studio / Cline

在设置中添加 MCP 服务器配置：

{
  "mcpServers": {
    "arthas-mcp": {
      "type": "streamableHttp",
      "url": "http://localhost:8563/mcp"
    }
  }
}

# 配置说明

# Arthas 配置项

配置项说明默认值
arthas.mcpEndpointMCP 服务的访问路径无（需要手动配置）
arthas.mcpProtocol传输协议模式：STREAMABLE（有状态）或 STATELESS（无状态）STREAMABLE
arthas.httpPortHTTP 服务端口8563
arthas.password认证密码（开启认证时使用）无

# 传输协议模式

Arthas MCP Server 支持两种传输协议模式：

  • STREAMABLE 模式（默认）：有状态模式，通过 HTTP/SSE 维持持久连接，支持长时间运行的命令（如 watch、trace、monitor 等流式工具）、进度通知和会话状态。适合交互式诊断场景。
  • STATELESS 模式：无状态模式，每个请求相互独立，适合简单的一次性查询场景。

在 arthas.properties 中配置：

arthas.mcpEndpoint=/mcp
# 可选，默认为 STREAMABLE
arthas.mcpProtocol=STREAMABLE

# 认证配置

当在配置文件中设置了 arthas.password 时，MCP Server 会自动开启鉴权功能。此时需要在 AI 客户端配置中添加认证头，携带的 Bearer Token 就是配置的密码值。

配置文件示例（arthas.properties）：

arthas.password=your-secure-password

AI 客户端配置示例：

{
  "mcpServers": {
    "arthas-mcp": {
      "type": "streamableHttp",
      "url": "http://localhost:8563/mcp",
      "headers": {
        "Authorization": "Bearer your-secure-password"
      }
    }
  }
}

注意

注意：Authorization header 中的 token 必须与 arthas.password 配置的值完全一致。

# viewfile 工具目录白名单配置

viewfile 工具默认只允许查看以下目录中的文件：

  • 当前工作目录下的 arthas-output 目录（若存在）
  • 用户 Home 目录下的 ~/logs/ 目录（若存在）

可通过环境变量扩展允许目录：

export ARTHAS_MCP_VIEWFILE_ALLOWED_DIRS=/path/to/dir1,/path/to/dir2
